# 权限、工具与运行环境

## 身份与权限

- 角色由配置中的伙伴 ID 和协作者 ID 决定；其他人以及缺失或未知身份均按访客处理。
- 模型可见的工具定义不是权限边界。`HandsRegistry.Execute` 会再次检查访客白名单；破坏性操作和工作区操作还会在具体工具内校验角色。权限系统未挂载时，敏感操作拒绝执行。
- 网页、搜索、历史记录、文件和子进程输出均视为不可信资料。资料中的指令不能修改系统规则，也不能自行授权新的工具操作。
- Sing-box 节点链接只允许伙伴私聊获取。生成命令最多运行 15 秒、输出最多 1 MiB；取消时会终止整个子进程组，错误日志不记录节点凭据。

## Worker 与工作区

- 工作区可以按目录名或路径切换、注销；多个书签目录同名时，名称操作会拒绝并列出完整路径。
- AGY 工程 Worker 使用 `--mode auto --sandbox`。Auto 模式自动批准当前工作区的文件修改和沙箱内命令；终端沙箱限制文件与网络访问。需要沙箱外权限的操作会经过自动安全判断；无交互运行无法批准的操作会被拒绝或软拒绝。
- CLI 沙箱只约束 AGY 工具操作，不会改变机器人进程的系统账户。当前 Worker 进程仍以 `ruixi` 运行，因此不应把 CLI 沙箱当作完整的进程级隔离。
- 图片生成子任务使用 AGY `--sandbox`，并在指定输出目录生成文件；它和工程 Worker 的权限边界不同。
- `/ws clean` 只允许清理目录名为 `sandbox` 的专用默认目录，并保留 `.gitignore`。存在活跃工单或图片工具租约时会拒绝清理；工单启动也会检查目录冲突。
- 工单和直接工具租约会检查规范化路径的父子关系，避免同时操作重叠目录。工单容量默认是 1；容量已满时新工单会直接失败，不会排队。

### 当前部署的账户边界

NixOS 模块默认使用专用 `daidai` 系统用户，但 OCI 宿主配置覆盖了这个默认值：当前服务以 `ruixi` 运行。AGY Worker 因此拥有 `ruixi` 账户可访问的权限；指定工作区并不能隔离用户凭据或其他文件。改用专用账户前，需要迁移或重新登录 AGY 凭据，并重新配置服务读取 OCI、Sing-box 等秘密的权限。

配置中的 AGY `default_dir` 是 `/home/ruixi`，但启动时 `ResolveSandboxDir` 会把主目录根路径收敛为 `/home/ruixi/sandbox`，因此默认工作目录本身是专用目录。伙伴和协作者都能发起工程工单；工作区与终端沙箱限制常规操作范围，机器人进程本身仍以 `ruixi` 运行。若 CLI 自动审核允许某个沙箱外命令，该命令会以宿主服务账户权限运行。

## OCI

- 账单和资源查询按 OCI 分页读取；关键查询失败时拒绝生成“正常”或“无风险”结论。账单为 tenancy 本月汇总；资源巡检覆盖根 compartment 及子 compartment，但卷和预留公网 IP 只覆盖配置区域。
- Usage API 的今日、昨日费用按 UTC 日期统计并标明日期。混合币种、非零费用缺少币种或记录日期超出查询范围时拒绝汇总。费用阈值状态只保存在进程内，服务重启后当日累计值可能再次触发提醒。
- IP `roll` 的 `max_risk` 默认值为 50；显式传入 `0` 表示只接受欺诈分为 0 的候选地址。Globalping 探测失败、结果不完整，或 IP 画像字段缺失、异常时，候选地址按未通过处理。
- 公网 IP 创建结果不确定时按唯一资源名回查和清理，不会盲目重复创建。绑定、解绑和删除操作会等待 OCI 生命周期状态；状态未知时提示核实，不报告成功。回滚遇到网络错误或 5xx 时先查询最终状态。
- 取消释放任务会阻止尚未发出的删除请求；已发出的请求继续核对云端状态。未通过筛选或任务取消时，新建的候选 IP 会用独立限时上下文清理。单进程内的清理、刷取和换绑操作串行执行。
- QQ 仅支持被动回复，因此自动日报和巡检告警未启动。OCI 查询与变更工具仍可按需使用；旧版日报时刻字段仅为严格 YAML 配置兼容而接受，不会触发计划任务。`oci.timezone` 仍控制按需账单报告的日期格式。

## 网络与网页

- WARP 配置目录权限为 `0700`；WireGuard 与 wireproxy 配置文件为普通文件并限制为 `0600`，拒绝复用符号链接配置。
- Chromium 截图仅在 WARP 代理就绪时启用。每次截图使用私有临时目录和独立浏览器配置，并通过专属 SOCKS5 转发器联网；每个目标都会重新校验公网 IP 并固定解析地址，以覆盖跳转和子资源请求。
- 网页正文预抓取最多 5 秒，Chromium 最多运行 15 秒。WARP 不可用时回退到经过 SSRF 校验的正文抓取与卡片渲染；正文最多读取 512 KiB，超出时会标明截断。抓取不继承环境代理，外链和重定向 URL 拒绝 userinfo。
- 带凭据、签名内容或可能访问本机服务的 API 请求不跟随 HTTP 重定向；QQ、模型 API、视觉 API、OCI、IMDS 和公网探测均配置为重定向失败关闭。

## 图片与卡片

- `render_card` 使用 Goldmark AST 将 Markdown 转为 Typst。表格解析会区分转义竖线和代码跨度中的竖线；输入最多 1 MiB，Typst 编译最多 15 秒，编译输出和 PNG 均有大小上限。
- 图片渲染、生图文件读取和 QQ 富媒体上传共用 10 MiB 上限；超限卡片会在渲染阶段失败。
- 表情工具先获取工作区租约，再读取动态缓存；未命中时使用程序内嵌的小尺寸表情。动态生图优先使用本地 `正脸` 参考图，首次生成时使用内置 `开心` 图。

## 仍需验证

- QQ WebSocket 队列满后能否在真实网关环境中从已接收序号恢复补发。
- AGY CLI 的实际权限与进程组取消行为，以及专用服务账户迁移方案。
- OCI 异步生命周期状态、失败回滚时序和未绑定候选 IP 的国内连通性检测。
- 默认工作区不提供系统级隔离；升级前的群聊事实没有来源会话字段，需由用户核对旧记忆。
