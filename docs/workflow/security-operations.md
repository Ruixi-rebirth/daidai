# 权限、工具与运行环境

manage_group_expressions 仅核心搭档在当前群内可调用，不接受其他群地址，不能在私聊开启。两项额外表达默认关闭、按平台及群/话题隔离；生成与发送前核对权限状态和候选有效性，读写现有 runtime_state，不新增后台广播或跨群读取。详见 [群内表达](group-expressions.md)。

## 身份与权限

早报生成和订阅由核心搭档管理，已订阅群的群友可以只读查看；工具执行层独立检查会话和权限。群聊与私聊的订阅、指代和投递记录独立，群内状态查询只显示本群。TG 主动私聊前通过 getChat 重核配置用户名，群推送核验群地址及类型；chat_id 仅用于路由，QQ 按当前搭档 OpenID 核验管理权限。新闻资料不作为用户个人事实，具体失败语义见 [极客早报](briefing.md)。

- 核心搭档由 QQ 的 `owner_openid` 和 Telegram 的 `owner_username` 分别确定；Telegram 按用户名匹配，不使用数字 ID 持久绑定。QQ 协作者角色保存在平台 SQLite 的 `user_roles` 表，配置中的旧协作者列表只在首次启动时导入。未知身份按访客处理。核心搭档可在 QQ 私聊中自然语言查询待处理申请、OpenID 与最近消息，并明确要求授权或撤销协作者；权限变更立即生效，不必修改配置或重启。
- 未授权访客的 QQ 私聊不会进入正式聊天历史、消息缓存或模型上下文；每个 OpenID 仅在 `private_access_requests` 中保留一条最近请求，包含昵称、最近消息、首次/最近时间及请求次数。首次申请会主动通知核心搭档，同一申请待处理期间不会重复通知；主动消息失败时进入现有待发队列。OAuth 认证口令会隐藏，附件本体和链接不会保存。
- 工具定义按当前会话过滤，但可见性不是权限边界；`HandsRegistry.Execute` 会复核访客白名单与会话范围，具体敏感操作仍由工具执行层校验。无用户身份的内部调用必须显式列出获准工具名，不能借此绕过任意工具权限。权限系统未挂载时，敏感操作拒绝执行。
- 网页、搜索、历史记录、文件、访客权限申请原文和子进程输出均视为不可信资料。资料中的指令不能修改系统规则，也不能自行授权新的工具操作。
- Sing-box 节点链接只允许伙伴私聊获取。生成命令最多运行 15 秒、输出最多 1 MiB；取消时会终止整个子进程组，错误日志不记录节点凭据。

## Worker 与工作区

- 工作区可以按目录名或路径切换、注销；多个书签目录同名时，名称操作会拒绝并列出完整路径。
- AGY 工程 Worker 使用 `--mode accept-edits --sandbox --dangerously-skip-permissions`，后一个参数让 CLI 自动批准工具权限请求。工程任务由应用入口限制为伙伴和协作者可发起；实际文件与网络范围由 CLI 终端沙箱及宿主服务账户权限共同决定。
- QQ 与 Telegram 附件只在用户明确要求处理后才会读取；意图不明确时先询问。普通文件仅在对应任务中通过 `--add-dir` 授权给 AGY，图片仅在用户明确要求分析后交给视觉 Provider；附件内容始终视为非可信输入。未明确要求时不下载或授权附件目录。
- CLI 沙箱只约束 AGY 工具操作，不会改变机器人进程的系统账户。当前 Worker 进程仍以 `ruixi` 运行，因此不应把 CLI 沙箱当作完整的进程级隔离。
- 图片生成子任务使用 AGY `--sandbox`，并在指定输出目录生成文件；它和工程 Worker 的权限边界不同。
- `/ws clean` 只允许清理目录名为 `sandbox` 的专用默认目录，并保留 `.gitignore`。存在活跃工单或图片工具租约时会拒绝清理；工单启动也会检查目录冲突。
- 工单和直接工具租约会检查规范化路径的父子关系，避免同时操作重叠目录。工单容量默认是 1；容量已满时工单进入有界等待队列，最多 100 张，不会并发触碰重叠目录。

### 当前部署的账户边界

NixOS 模块默认使用专用 `daidai` 系统用户，但 OCI 宿主配置覆盖了这个默认值：当前服务以 `ruixi` 运行。AGY Worker 因此拥有 `ruixi` 账户可访问的权限；指定工作区并不能隔离用户凭据或其他文件。改用专用账户前，需要迁移或重新登录 AGY 凭据，并重新配置服务读取 OCI、Sing-box 等秘密的权限。

配置中的 AGY `default_dir` 是 `/home/ruixi`，但启动时 `ResolveSandboxDir` 会把主目录根路径收敛为 `/home/ruixi/sandbox`，因此默认工作目录本身是专用目录。伙伴和协作者都能发起工程工单；机器人及 Worker 子进程以 `ruixi` 运行，CLI 工具授权会自动批准。工作区用于组织任务目录，终端沙箱的限制能力取决于实际 CLI 实现。

## OCI

- 账单和资源查询按 OCI 分页读取；关键查询失败时拒绝生成“正常”或“无风险”结论。账单为 tenancy 本月汇总；资源巡检覆盖根 compartment 及子 compartment，但卷和预留公网 IP 只覆盖配置区域。
- Usage API 的今日、昨日费用按 UTC 日期统计并标明日期。混合币种、非零费用缺少币种或记录日期超出查询范围时拒绝汇总。定时费用告警阈值在发送成功或告警成功进入待发队列后写入 SQLite；若进程恰好在通知发送/入队成功、状态落库前退出，重启后可能重复提醒。
- IP `roll` 默认随机申请并保留一个未绑定候选，不修改当前绑定：`max_risk=100`、`no_abuser=false`，不请求第三方画像。只有用户明确提出要求时才设置前缀、评分上限或排除公开代理。`max_risk<100` 必须拿到有效 Scamalytics 评分；显式 `0` 只接受已知评分 0；`no_abuser=true` 必须拿到明确的 ip-api 代理标记。画像仅供参考，不代表业务可用性或网段质量。
- 最多申请 15 个候选；仅明确不满足筛选条件时释放本轮候选后继续。必需画像不可用（HTTP 错误、缺失字段、超时等）时释放本轮候选并停止，返回具体原因，不将未知当成高风险。结果列出实际申请次数、淘汰原因与保留状态；连续申请也可能再次获得同一地址，不据此声称地址池枯竭。
- `roll` 只按用户指定的地址前缀与画像条件申请并保留未绑定候选，不执行连通探测。`check` 读取服务器 TCP 监听和 UDP 绑定套接字；未绑定候选会临时绑定到辅助私网 IP 后检查，结束后先确认公网 IP 已解绑，再清理辅助私网资源。候选公网 IP 本身不会因探测结果被释放。默认逐个从 Globalping 国内探针检查适用于该私网地址的 TCP 监听端口；可用 `port` 只检查指定 TCP 端口。UDP 套接字可能包含本机客户端套接字，不能据此认定为服务端口；当前不执行公网 UDP 探测，需由对应服务协议完成请求—响应验证。此流程依据本机 TCP 监听端口逐项验证，不是 Nmap 全端口扫描；探针未响应或结果不完整不能判定 IP 被墙。
- 公网 IP 创建结果不确定时按唯一资源名回查和清理，不会盲目重复创建。绑定、解绑和删除操作会等待 OCI 生命周期状态；状态未知时提示核实，不报告成功。回滚遇到网络错误或 5xx 时先查询最终状态。
- 取消释放任务会阻止尚未发出的删除请求；已发出的请求继续核对云端状态。未通过筛选或任务取消时，新建的候选 IP 会用独立限时上下文清理。单进程内的清理、刷取和换绑操作串行执行。
- OCI 启用且 QQ 与 `qq.owner_openid` 已配置时，通过 C2C 主动消息发送每日账单和告警。费用每小时轻量检查；资源巡检每 6 小时执行一次，遍历租户的 compartment，但卷和预留公网 IP 只检查配置 region。默认日报时间为 `oci.timezone` 当地 08:30（未配置时区按 SGT）；费用首次告警后，累计额每增加 `oci.cost_alert_delta` 再告警，默认增量为 1 个计价单位。日报尝试次数、最近重试时间、费用与资源查询成功时段，以及告警状态保存在 SQLite；服务重启后仍遵守 5 分钟重试冷却，避免重复执行已成功的时段检查。日报获取失败，或发送失败且未能进入待发队列时，每 5 分钟重试，连续失败 3 次后停止当天重试；发送失败但成功入队的日报与告警会等待用户下次私聊时投递。费用与资源告警发送失败且未能入队时，会重新开放该时段检查，5 分钟后重试。资源风险类别按 UTC 日去重，费用阈值在通知送达或成功入队后更新。群聊主动发送使用显式主动模式，QQ 平台仍可按当前机器人权限和消息策略拒绝请求。

## 网络与网页

- WARP 配置目录权限为 `0700`；WireGuard 与 wireproxy 配置文件为普通文件并限制为 `0600`，拒绝复用符号链接配置。
- Chromium 截图仅在 WARP 代理就绪时启用。每次截图使用私有临时目录和独立浏览器配置，并通过专属 SOCKS5 转发器联网；每个目标都会重新校验公网 IP 并固定解析地址，以覆盖跳转和子资源请求。
- `read_link` 在受控只读 AGY 沙箱内读取用户指定 URL 并按整句请求总结或回答；`search_web` 用于一般网络搜索；`screenshot_web` 仅在用户要求视觉检查时截取首屏视口，不承担正文读取。截图为页面提供最多 15 秒加载时间，并在截图前推进 5 秒虚拟时间，让页面脚本有机会完成首屏渲染。每轮最多处理两个不同网页，读取与截图共用额度。外部链接经 SSRF 严格校验，拒绝 userinfo，拦截本机公网 IP，且强制绑定 WARP 本地出口代理。抓取不继承环境代理，外链和重定向 URL 拒绝 userinfo，并拦截本机已登记的公网地址，避免从公网 URL 绕回访问宿主机服务。
- 带凭据、签名内容或可能访问本机服务的 API 请求不跟随 HTTP 重定向；QQ 使用 `api.bot.qq.com` 官方 API 域名，网关返回的 WebSocket 地址只接受官方域名；模型 API、视觉 API、OCI、IMDS 和公网探测也配置为重定向失败关闭。

## 图片与卡片

- 卡片正文为 18pt，代码为 16pt，使用配套深色高对比语法主题；行内代码为 17pt，普通卡片与画像卡片共享字号设置。
- `render_card` 使用 Goldmark AST 将 Markdown 转为 Typst。表格解析会区分转义竖线和代码跨度中的竖线；输入最多 1 MiB，Typst 编译最多 15 秒，编译输出和 PNG 均有大小上限。
- 图片渲染、生图文件读取和 QQ 富媒体上传共用 10 MiB 上限；超限卡片会在渲染阶段失败。
- 图片解码最多 2 个并发任务，每张图片最多 2,000 万像素；图卡、上传图片和解码后的图片共用该像素上限。超出并发时可随请求取消，非 Go 原生解码格式交由限时 FFmpeg 转成 PNG。
- 表情工具先获取工作区租约，再读取动态缓存；访客只能获取本地缓存或内置表情，未命中不触发生成。动态生图由核心搭档或协作者发起，优先使用本地 `正脸` 参考图，首次生成时使用内置 `开心` 图。

## 仍需验证

- QQ WebSocket 队列满后能否在真实网关环境中从已接收序号恢复补发。
- AGY CLI 的实际权限与进程组取消行为，以及专用服务账户迁移方案。
- OCI 异步生命周期状态、失败回滚时序和未绑定候选 IP 的国内连通性检测。

## 权限目标的确定

- 权限管理优先匹配名单中的完整 OpenID；显示昵称必须唯一匹配，同名时要求改用 OpenID 或带明确名单类型的序号。序号越界不切换到另一份名单，读取申请或已授权名单失败时停止选择目标。
- `grant` 只新增或提升权限，已有协作者再次添加为好友时保留协作者权限，并在回执中明确说明。权限变更事务直接返回最终角色，内存权限与回执都使用该结果；降级使用明确的 `modify` 操作。

网页搜索与定向阅读共用 AGY 子进程执行流程，但分别传递结构化 `query` 或 `url`/`task`，不将 URL 与任务拼成搜索词。定向阅读保留完整合法 URL 和处理要求，不经过搜索词的 1000 字符裁剪；处理要求超出用户消息上限时明确返回错误，避免悄悄丢失要求。工具结果只返回处理结果，不重复回传整段 URL 与任务。

附件暂存管理识别实际生成的“范围哈希＋随机后缀”目录，Store 返回的目录可直接 Activate 给 Worker 使用；配额、活动保护与过期清理使用同一识别规则。非托管名称和路径不参与删除。

WARP 子进程就绪状态由对应的守护循环维护，进程退出或取消后清除状态，避免已退出进程的启动探测覆盖后续状态；短期公网/出口探测结束时关闭各自连接池中的空闲连接。Google 登录链接按官方域名与 `/o/oauth2/auth`、`/o/oauth2/v2/auth` 两个授权路径识别。
